## 目的
- プログラムを起動したら10秒間音声を録音し，録音された内容を文字起こしして，テキストファイルに保存するアプリケーションをグループで作成

## モジュールの準備

- ffmpeg
- requirements.txt

## 全体での決め事
### 作るもの
- main.py メイン
- record.py 録音
- mojiokoshi.py 文字起こし
- hozon.py 保存

### リーダー(k25112)
- main.py メイン:他のファイルの処理を順番に呼び出す
- ファイルは同じ階層に作る

### 音声データ作成(k25046)
- record.py 録音
- 引数：なし
- 出力ファイル名：audio-output.wav
- 10秒録音してファイルに保存

### 文字起こし処理(k25002)
- mojiokoshi.py 文字起こし
- 戻り値：文字起こしデータ(テキスト) 
- ファイルから読み込んで文字起こし

### テキストデータ保存(k25072)
- hozon.py 保存
- 引数：文字起こしデータ(テキスト)
- 出力ファイル名：hozon.txt
- 上書きしない→同じテキストファイルで行数増やす
- テキストを受け取ってテキストファイルを作る
